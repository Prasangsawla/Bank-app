# 🏦 Console Based Banking Application (Java)

A simple **console-based banking system** built using Java.  
This project demonstrates core Java concepts like OOP, interfaces, service layers, and basic data handling.

---

## 🚀 Features

- Open a new bank account  
- Deposit money  
- Withdraw money  
- Search account by account number  
- Transfer money between accounts  
- Load / View account statement  
- Exit system safely  

---

## 🛠 Tech Stack

- Java  
- OOP Principles  
- Interface & Service Implementation  
- Console-based UI  
- Scanner for user input  

---
